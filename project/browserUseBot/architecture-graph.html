BrowserUseBot — Architecture

A 24/7 supervised browser-agent: you drive it from Telegram, it runs browser and API tasks on an always-on AWS host, and when a task hits a login wall it hands the live browser back to you instead of evading it. Code ships from the local dev environment through a GitHub Actions test-gated pipeline; every agent step is traced to Langfuse.

Task flow

You message the bot (or the scheduler fires a cron job) → the gateway hands the raw request to the intent router, an LLM call that picks a capability from the registry and extracts typed params. The capability (GeneralBrowse for one-offs, BatchCrawl for long-horizon harvesting) composes the shared substrate: BrowserAgentRunner wraps browser-use, which drives the headful Chromium over CDP against the target web — API-first, browser-second. Results and artifacts land in the workspace; a summary returns to Telegram.

Login handoff · human-in-the-loop

  1. The per-step handoff hook detects a login/2FA wall and pauses the agent — it never evades.
  2. The gateway sends you a 🔐 link over Telegram: http://<EC2-IP>:8770/vnc.html?token=… — short-lived, single-use.
  3. Your phone opens noVNC, a live view of the agent's own browser; you log in exactly as if sitting at the machine.
  4. You send /done → agent resumes. Cookies persist in the persistent profile, so logins are rare (once per site until expiry).

CI/CD · push-to-deploy

git push main triggers GitHub Actions: a test job on ubuntu-latest (same OS family as prod) gates the deploy — a Linux failure blocks shipping. The deploy job SSHes into EC2 and runs deploy.sh: hard-reset to origin/main, reinstall, restart the systemd service, then health-check with auto-rollback to the previous commit if the new version fails to start. .env, workspace, and browser profile are git-ignored and survive every deploy. Rollback = deploy any tag. No Docker — deliberate, until multi-box scale.

Observability · Langfuse

Every run emits per-step traces (plan → fetch → parse → notify) with status, latency, and token cost. Domain metrics ride on top: new-job detection precision/recall, dedup correctness, extraction field accuracy against a hand-labeled gold set. Scheduled evals re-run these and alert regressions back through Telegram — the layer that makes this a platform, not a script.
